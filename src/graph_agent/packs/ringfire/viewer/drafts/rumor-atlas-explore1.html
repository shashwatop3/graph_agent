Rumor Atlas

Two pictures of how a lie travels through a team of agents. Each one draws the same game twice: once with graph memory, once with prompt-only memory, on the same axes.

PLATE IThe rumour timetable

a lie, hop by hop a true report trust cut agent's fields on fire burnt imposter row

Read it like a train timetable. Days run left to right, agents top to bottom. Every message is a stroke from the sender on one day to the receiver on the next, so a report passed down the ring becomes a steep diagonal. The fire shows as a shallow orange band underneath: it moves one field a day, while news moves one agent a day. Hover a streak to follow one rumour.

PLATE IIContamination filmstrip

clean heard a live lie has passed a lie on cut a liar that day imposter

One small ring per day, agents in ring order with A0 at the top. An agent is contaminated while it holds a lie about a field the fire hasn't reached yet. With graph memory a lie stops counting once the agent cuts trust in someone on its route, because the belief loses its support. Watch how far the pink spreads in each row.
